# Fox Evolution v3.1 — плавность и естественность

Цель итерации — сделать уже утверждённое визуальное взросление лисёнка **плавнее и менее навязчивым**, сохранив узнаваемый WebP-атлас, заметную золотую вспышку и исходные правила XP/монет. Художественные ассеты не заменяются.

## Движение

- В исходной v3 изображение резко проявлялось через маленькую круглую маску одновременно с крупным прыжком, вращением и девятью искрами; несколько эффектов конкурировали визуально. В v3.1 временный слой с **предыдущим возрастом** плавно растворяется поверх новой иллюстрации за 650 мс. Рисунок нового возраста слегка поднимается на 2 px и без резкого скачка возвращается к нейтральному масштабу за 750 мс.
- Сохраняется золотая подсветка (короткий мягкий пульс). Прыжок заменён естественным коротким кивком (до 3 px и 1,5°). Искр теперь шесть, они меньше и исчезают раньше. Обычный список задач не перекрывается.
- При `prefers-reduced-motion: reduce` нет дополнительного слоя, движения или искр: сразу показываются правильная стадия и доступное текстовое поздравление.
- Длительность уведомления после начисления XP сокращена с 3,4 до 2,8 сек. Повторное открытие страницы не запускает превращение. Косметика, уровень, энергия, импорт/экспорт и кошелёк остаются прежними.

## Звук

- Раньше при открытии возраста после обычного звука завершения следовали сразу три мелодии: монеты, XP и новый уровень. Теперь **только для настоящего взросления лисёнка** воспроизводится один более мягкий трёхнотный сигнал после завершения; отдельные мелодии монет и XP для него не наслаиваются.
- Для обычных задач без смены возрастной стадии привычные звуки и эффекты **не меняются**.
- Уровень громкости нового сигнала снижен в исходном `effects.js`, а демонстрационный WebAudio-отклик синхронизирован с ним. Выключатель «Отклик» полностью сохраняет силу.

## Оценка на телефоне

- Сворачиваемая форма показывает **один из пяти вопросов за раз**. «Назад» и «Следующий вопрос» переключают вопросы; ответы остаются необязательными. При копировании текст по-прежнему формируется локально, а после перезагрузки все оценки и комментарий сбрасываются.
- Если браузер поддерживает `navigator.share`, появляется отдельная кнопка «Поделиться через телефон». **Только явное нажатие** открывает системное меню выбора адресата, без автоматического отправления. Если API нет, остаётся кнопка «Скопировать отзыв» с ручным fallback.

- Обновлены `tests/fox-ceremony.mjs`, `tests/fox-phone-preview.mjs`, `tests/fox-phone-feedback.mjs` для нового визуального поведения, пошагового опроса и явного native share. Запуск в Chromium, Firefox и WebKit вместе со всем существующим QA-набором.

Ранее полученные субъективные оценки использованы **только как направление для изменений UX**; персональные отзывы и комментарии на GitHub не публикуются.
