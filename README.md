# Сделано

Небольшое мобильное веб-приложение для закрытия задач — без сложных планировщиков.

**Демо:** https://safal207.github.io/todo-list/

**Персональная карточка:** при открытии «Поделиться прогрессом» браузер создаёт JPG 1200×630 с крупным «ШАГ», реальными счётчиками выполненных задач, процентом и CTA «ТВОЙ ХОД! ЗАПИШИ ПЕРВУЮ ЗАДАЧУ». Картинка видна в окне отправки, скачивается локально или передаётся как фотография через системное меню телефона. В JPG не попадают названия задач, таймеры и другие персональные данные. При недоступности Canvas JPG предусмотрен старый общий постер. Генерация не требует сервера.

**Предпросмотр ссылки:** Open Graph / Twitter Card используют компактный фирменный JPEG `assets/share-step-1-v2.jpg` (1200×630, около 112 КБ), без вымышленных процентов. Для прогресса теперь есть отдельная страница `/invite/` со своим `og:url` и рекламным CTA: ссылка `/invite/?share=1&done=N&total=M&utm_campaign=telegram_invite_v1` показывает процент друга и кнопку «Записать первую задачу». Это отделяет приглашение от старой закэшированной главной страницы. Telegram может по-прежнему скрывать обложку из-за собственного кэша или настроек предпросмотра. У социальной ссылки остаётся общий статичный Open Graph постер (GitHub Pages не умеет формировать отдельную картинку для каждого набора параметров). Для реальных персональных цифр следует делиться **картинкой как фотографией**, а не только ссылкой. На телефонах без отправки файлов можно скачать персональный JPG и приложить его вручную. Названия задач не передаются.

## Что умеет

**Достижение «3 шага сделано»:** когда три разные задачи отмечены выполненными одновременно впервые, появляется компактная награда с крупной цифрой 3 и действиями «Следующий шаг», «Поделиться достижением» и «Не сейчас». Награда не блокирует список, не создаёт задач сама и не конфликтует с «Первой победой» или Upsell. После закрытия поздравления остаётся небольшой знак достижения. Флаг сохраняется в `localStorage` (`sdelano.three-steps.v1`), поэтому повторная галочка, повторное открытие или удаление задачи не показывают награду повторно. Уже выполненные три задачи из старого сохранения дают тихий значок без ложного нового поздравления. Считаются разные записи задач, а не число переключений галочки. Данные не отправляются на сервер.

**Upsell «Ещё один шаг»:** для пользователя, уже выполнившего первое дело, панель прогресса предлагает ровно одно следующее действие. Если остались открытые задачи — показывает название первой незавершённой задачи и переводит к её галочке даже из фильтра «Готово»; если все дела закрыты — предлагает записать новую задачу. Переход не завершает задачи и не добавляет новые автоматически. В момент показа первой победы второе предложение скрыто, чтобы не было конкурирующих CTA. Для новых пользователей остаётся только двухшаговая первая миссия. Это бесплатное продолжение работы, а не платёжный upsell.

**Tripwire «Первая победа»:** для новых пользователей индикатор «Миссия 1 из 2» предлагает записать одну небольшую задачу, затем «Миссия 2 из 2» переводит к первому незавершённому делу. После первой галочки появляется ненавязчивая карточка «Первый шаг сделан!» с кнопками «Записать следующий шаг», «Поделиться победой» и «Не сейчас». Кнопка следующего шага только переводит фокус на поле ввода — новая задача без решения пользователя не создаётся. Карточка показывается один раз, признак достижения сохраняется в `localStorage`; выполненные ранее задачи и журнал действий учитываются, поэтому старым пользователям награда повторно не выдаётся. Список остаётся бесплатным; это продуктовая активация, а не платёжная воронка.

- Добавить задачу — индивидуальный секундомер стартует автоматически.
- Поставить галочку — секундомер останавливается и показывает итог в секундах, минутах, часах и днях.
- Вернуть задачу в работу — отсчёт продолжается с накопленного времени. Пока задача закрыта, отсчёт приостановлен.
- Фильтры «Все», «В работе», «Готово», удаление и общий прогресс.
- Кнопка «Поделиться прогрессом» всегда реагирует на нажатие: при пустом списке предлагает добавить первую задачу, иначе открывает понятное окно с результатом, **Telegram**, **WhatsApp**, системной отправкой (где поддерживается) и копируемым вручную текстом. Даже без разрешения буфера обмена можно выделить приглашение.
- Ссылка на конкретное достижение содержит только счётчики `done`/`total`; у получателя она открывает **приглашение с прогрессом друга и CTA «Начать свои задачи»**, но не чужой список. Это referral/upsell-воронка для знакомства с бесплатным сервисом. Названия задач, таймеры и личные данные не передаются.
- Короткие оригинальные звуки, небольшая анимация и вибрация там, где её поддерживает устройство. Кнопка «Отклик» выключает и звук, и вибрацию.
- Небольшая анимация логотипа при открытии. При настройке «Меньше движения» она не показывается.

Важное уточнение: таймер измеряет **прошедшее календарное время с момента создания задачи, пока она открыта**, а не минуты активной работы пользователя. Если вкладка закрыта, отсчёт продолжается по меткам времени и корректно восстанавливается. По завершении он останавливается.

Данные сохраняются в `localStorage` **текущего браузера**. Синхронизации между устройствами нет. Старые задачи остаются: у открытых задач отсчёт начнётся с первого открытия обновлённой версии, а у ранее завершённых без времени будет честная пометка «время неизвестно».

Звуки запускаются только после действий пользователя, так как браузеры блокируют автоматическое воспроизведение. Вибрация зависит от устройства и браузера, например Safari на iPhone не поддерживает `navigator.vibrate()`.

## Запуск

Откройте `index.html` через любой статический HTTP-сервер:

```bash
python3 -m http.server 8765
```

Затем откройте http://localhost:8765/

Сборка и бекенд не требуются. В репозитории есть тесты Playwright и workflow GitHub Actions (мобильные ширины 320 и 390 px, десктоп 1280 px).
