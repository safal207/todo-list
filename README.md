# Список задач

Небольшое тестовое веб-приложение на HTML, CSS и JavaScript. Можно добавить задачу, отметить её выполненной, вернуть в работу и удалить. Список и отметки сохраняются после перезагрузки страницы в том же браузере.

## Запуск

Откройте [демо на GitHub Pages](https://safal207.github.io/todo-list/). Для локального запуска скачайте репозиторий и откройте `index.html` через любой статический HTTP-сервер, например `python -m http.server 8000`. Затем перейдите на `http://localhost:8000`. Сборка и установка зависимостей не требуются.

## Как проверить

1. Добавьте две задачи, одну кнопкой «Добавить», другую клавишей Enter.
2. Отметьте первую задачу выполненной и обновите страницу. Проверьте, что обе задачи и отметка сохранились.
3. Снимите отметку, удалите вторую задачу и снова обновите страницу. В списке должна остаться первая задача без отметки.
4. Удалите последнюю задачу. После обновления должен остаться пустой список.

Данные хранятся в `localStorage` текущего браузера. Для задач с одинаковыми названиями отметка и удаление работают независимо.
