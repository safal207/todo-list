# Сделано

Небольшое мобильное веб-приложение для закрытия задач — без сложных планировщиков.

**Демо:** https://safal207.github.io/todo-list/

**Предпросмотр ссылки:** Open Graph / Twitter Card используют компактный фирменный JPEG `assets/share-step-1-v2.jpg` (1200×630, около 112 КБ) с большим призывом «ШАГ 1 — ЗАПИШИ ЗАДАЧУ» без вымышленных процентов. При отправке прогресса реальные цифры указаны в сообщении и на целевой странице, но названия задач не передаются. Ссылка получает `utm_campaign=step_one_poster_v2` для обновления предпросмотра; Telegram и другие мессенджеры могут сохранять старую картинку или отображать только текст из собственного кэша.

## Что умеет

- Добавить задачу — индивидуальный секундомер стартует автоматически.
- Поставить галочку — секундомер останавливается и показывает итог в секундах, минутах, часах и днях.
- Вернуть задачу в работу — отсчёт продолжается с накопленного времени. Пока задача закрыта, отсчёт приостановлен.
- Фильтры «Все», «В работе», «Готово», удаление и общий прогресс.
- Кнопка «Поделиться прогрессом» всегда реагирует на нажатие: при пустом списке предлагает добавить первую задачу, иначе открывает понятное окно с результатом, **Telegram**, **WhatsApp**, системной отправкой (где поддерживается) и копируемым вручную текстом. Даже без разрешения буфера обмена можно выделить приглашение.
- Ссылка на конкретное достижение содержит только счётчики `done`/`total`; у получателя она открывает **приглашение с прогрессом друга и CTA «Начать свои задачи»**, но не чужой список. Это referral/upsell-воронка для знакомства с бесплатным сервисом. Названия задач, таймеры и личные данные не передаются.
- Короткие оригинальные звуки, небольшая анимация и вибрация там, где её поддерживает устройство. Кнопка «Отклик» выключает и звук, и вибрацию.
- Небольшая анимация логотипа при открытии. При настройке «Меньше движения» она не показывается.

Важное уточнение: таймер измеряет **прошедшее календарное время с момента создания задачи, пока она открыта**, а не минуты активной работы пользователя. Если вкладка закрыта, отсчёт продолжается по меткам времени и корректно восстанавливается. По завершении он останавливается.

Данные сохраняются в `localStorage` **текущего браузера**. Синхронизации между устройствами нет. Старые задачи остаются: у открытых задач отсчёт начнётся с первого открытия обновлённой версии, а у ранее завершённых без времени будет честная пометка «время неизвестно».

Звуки запускаются только после действий пользователя, так как браузеры блокируют автоматическое воспроизведение. Вибрация зависит от устройства и браузера, например Safari на iPhone не поддерживает `navigator.vibrate()`.

## Запуск

Откройте `index.html` через любой статический HTTP-сервер:

```bash
python3 -m http.server 8765
```

Затем откройте http://localhost:8765/

Сборка и бекенд не требуются. В репозитории есть тесты Playwright и workflow GitHub Actions (мобильные ширины 320 и 390 px, десктоп 1280 px).
